# ⚛️ React Learning & Practice Projects

A repository containing hands-on projects and exercises built while mastering modern React, ranging from fundamental concepts to full-featured single-page applications.

---

## 🛠️ Tech Stack
- **Core:** React, JavaScript (ES6+), TypeScript, HTML5, CSS3
- **State Management:** Context API, `useReducer`, Redux
- **Routing:** React Router DOM
- **Forms & Validation:** Formik, Yup
- **UI & Styling:** Material UI (MUI), CSS Modules
- **APIs & Libraries:** REST APIs, Fetch API, Leaflet Maps

---

## 🌟 Featured Projects

| Project | Key Technologies & Concepts | Description |
| :--- | :--- | :--- |
| **WorldWise** | React Router, Context API, Leaflet | Interactive travel tracking app displaying visited cities on an interactive map. |
| **usePopcorn** | Custom Hooks, LocalStorage, OMDB API | Movie search engine and watchlist manager with user ratings and persistent storage. |
| **React Quiz** | `useReducer`, Timer logic | Quiz application featuring question scoring, response timers, and progress tracking. |
| **Atomic Blog** | Context API, Performance Optimization | Blog application demonstrating context-based state sharing and re-render optimizations. |
| **Eat-N-Split** | Controlled Components, State Lifting | Expense-sharing calculator for splitting bills and tracking balances among friends. |
| **Travel List** | Controlled Components, Derived State | Packing checklist tool supporting item sorting, packing status, and real-time stats. |
| **Pizza Menu** | Components, Props, Conditional Rendering | Interactive digital restaurant menu displaying item availability and opening hours. |
| **Steps** | Local State (`useState`) | Multi-step interactive flow component for tracking sequential progress. |
| **My Book Collections** | State Management, Component Architecture | Personal library manager to organize, track, and browse book collections. |
| **How React Works** | React Internals | Exploration project examining Virtual DOM rendering, reconciliation, and component lifecycles. |
